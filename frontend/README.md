# JobFit Frontend (React + Vite)

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

The app will be available at http://localhost:3000

## Features

- Landing page with hero and stats
- Onboarding questionnaire (5 questions)
- Job listing with filters and search
- Job detail with requirements
- Resume analysis and fit scoring
- 7-day learning roadmap
- Application tracker

## Project Structure

```
src/
├── components/     # Reusable components
├── pages/          # Page components
├── services/       # API calls
└── utils/          # Helper functions
```

## Building for Production

```bash
npm run build
```
